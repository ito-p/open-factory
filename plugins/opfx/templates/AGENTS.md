## opfx rules (do not remove)
- One change per Issue, branch `factory/<change>`, worktree `../<repo>-wt/<change>`; a worker touches only its own worktree.
- Never edit `openspec/specs/**` directly; the source of truth changes only through `openspec archive` run by `archive.sh`.
- Never edit `.claude/commands/opsx/*` or `.claude/skills/openspec-*` (generated by OpenSpec).
- Never create approval files; human approval lives only in GitHub comments and labels.
- Reviews and rubric verdicts follow `.factory/rubric.md`; numbers (rounds, retries) come from `.factory/config.json`.
